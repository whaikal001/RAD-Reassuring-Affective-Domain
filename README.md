# SocializerAI
SocializerAI is an empathetic AI chatbot designed to provide social and mental health guidance. It leverages a modern full-stack architecture to create a supportive environment for users to improve their social well-being.

## Features 
Empathetic Chat Interface: Real-time AI interactions focused on emotional intelligence.

Responsive UI: A clean, modern landing page and dashboard built with Angular.

Secure Backend: Robust data handling using Spring Boot and Supabase.

System Integration: Seamless communication between the mobile and web components.

## Tech Stack 
Frontend: Angular, CSS

Backend: Spring Boot

Database: Supabase / MySQL

Design: Figma (Low-fidelity Prototyping)
